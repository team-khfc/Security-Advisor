# SecurityAdvisor 프런트엔드

2026-11-06 업데이트된 `보안길잡이 디자인시안 프로토타입/`의 모듈형 10개 화면을 기준으로 만든 실제 API 연결 프런트엔드입니다. 실행 가능한 업무 화면과 합성 데이터 디자인 미리보기를 분리합니다.

## 실행

```sh
npm ci
npm run dev
```

- 프런트: `http://securityadvisor.localhost:3000`
- 서버: `http://api.securityadvisor.localhost:8080`
- `/login`: 서버 발급 계정 로그인. 역할·기관은 인증된 세션을 따릅니다.
- `/requests`: 신청 현황 / 담당자 협의 요청함.
- `/design-preview/requests`: 서버 없이 확인 가능한 합성 디자인 미리보기.
- `/swagger-ui.html`: 같은 출처로 프록시한 서버 OpenAPI UI.

브라우저는 상대 경로 `/api`만 호출합니다. `API_ORIGIN`의 기본값은 `http://localhost:8080`이며 Next 빌드 시 rewrite에 반영됩니다. 컨테이너는 Dockerfile의 build arg로 내부 서버 주소를 받습니다.

## 구조

| 경계 | 책임 |
| --- | --- |
| `features/request` | 신청 생성, 자료 업로드·인터뷰, 목록·단계 조회, 통신 정보 |
| `features/review` | 인프라 할당, 협의, 최종 확인, 반환, 종결·철회 |
| `features/document` | 현재 문서 표시·다운로드, 차수별 불변 제출본 조회 |
| `features/configuration` | 기관 질문·고정 절차·양식 안내·게시 버전·컨텍스트 |
| `features/knowledge` | 공개 자료 목록·편집 요약 벡터 검색 |
| `features/llm` | 목적별 최신 모델 구성, 담당자 질의, 최종 초안 생성·사람 확인 |
| `features/auth` | 세션·CSRF·재인증·사용자별 메모리 초안 |
| `features/preview` | 읽기전용 합성 예시와 모든 업무 상태 |

`public/assets/design/`은 최신 디자인 CSS를 바탕으로 한 적용본입니다. design.md v3.1 부록 A에 따라 루트를 62.5%로 조정하고 본문 zoom을 제거했습니다. React 구조는 `styles/components.css`, 화면은 `styles/application.css`, 의미 토큰 연결은 `styles/tokens.css`, 접근성·확대·다크 모드 보강은 `styles/accessibility.css`에서 관리합니다. 기본 본문은 17px이며 화면 설정에서 보통·크게·아주 크게와 기기 설정·밝게·어둡게를 선택할 수 있습니다. 표시 설정만 브라우저에 저장하고 업무 데이터는 저장하지 않습니다. KRDS 원본 토큰·실제 Pretendard GOV 400/700 폰트·라이선스는 `public/assets/vendor/`에 보관합니다.

## 동작과 경계

절차는 작성 → 담당자 협의 → 사용자 최종 검토 → 확정·관리의 4단계입니다. 인프라 할당 완료는 파랑, 양측 협의 완료는 초록으로 구분합니다. 종결·철회 상태는 사유와 이력·문서 조회만 제공하며 업무 변경 행동을 숨깁니다. 차수 반환에는 사유·대상이 필요하며 기존 값과 이력은 보존됩니다. 반환 알림에서 해당 항목으로 이동하고, 보완 필드는 사유·배지·왼쪽 선으로 표시합니다. 서버의 `returnItems.previousValue`가 있으면 반환 당시 값도 비교할 수 있습니다. 이전 버전에서 생성되어 이 값이 없는 기록은 원본을 만들어 표시하지 않습니다. AI가 만든 최종 초안도 사람의 확인 전까지 미확정입니다. 서류 확정은 장비 적용을 실행하지 않습니다.

파일은 UTF-8 TXT/MD, 1MiB 이하 1개를 지원합니다. 선택만으로 전송하지 않고 명시적 분석 시작에서 업로드합니다. 문서 내려받기는 HTML이며 공식 양식 파일 업로드·PDF·DOCX 발급은 연결되지 않았습니다. 방화벽 장비 조회·적용·트래픽 수집도 연결되지 않았습니다.

예시 모드는 외부 LLM을 호출하지 않습니다. 실제 연결 설정을 저장해도 실제 모델 실행 성공을 뜻하지 않으며, 각 실행 결과의 모드·제공자·근거를 확인해야 합니다. 공개 자료 검색은 공식 페이지의 편집 요약 범위로 PDF 전문 색인을 주장하지 않습니다.

미저장 초안은 같은 탭 메모리에만 보관합니다. 동일 계정 재인증과 409 충돌에서 입력을 보존하며, 명시적 로그아웃·다른 계정 로그인 시 캐시와 초안을 지웁니다. 새로고침·브라우저 종료 후 복구는 지원하지 않습니다.

## 검사

```sh
npm run format
npm run check
npm run build
```

`check`는 Prettier, TypeScript strict, ESLint, Vitest/Testing Library를 실행합니다. 실제 서버 권한·기관 격리·반환과 제출본 불변성은 백엔드 테스트와 통합 실행으로 검증합니다. 실행하지 않은 검사를 통과로 보고하지 않습니다.

## 시연 자료와 검증 범위

모든 시연 기관·사용자·서버·통신 정보는 합성 자료입니다. 실제 내부망 IP, 개인정보, 비공개 규정, 비밀값은 시연 입력·소스·스크린샷에 넣지 않습니다. `/design-preview/*`는 읽기 전용 fixture이며 저장이나 외부 AI 실행 성공을 표시하지 않습니다. 업무 화면은 인증 API의 실제 성공 응답에 따라 저장·검토·제출 결과를 표시하고, 예시 분석 모드는 분석 결과에 따로 표시합니다.

브라우저 통합 검사는 별도로 수행해야 합니다. 자동 테스트만으로 모든 화면의 KRDS·접근성 준수, 보조기기, 200% 글자·400% 브라우저 확대를 통과했다고 판단하지 않습니다. 개발 통합 포트가 18080일 경우 `API_ORIGIN=http://127.0.0.1:18080 npm run build` 후 `npm start -- --port 13000`으로 실행합니다.
