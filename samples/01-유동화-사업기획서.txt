[시연용 합성 사업기획서]
기관: 한국주택금융공사
사업명: 유동화 자료 전송 서비스 개선
주관 부서: 유동화자산처
목적: 합성 집계 자료를 정기적으로 전달하여 담당자의 반복 입력을 줄인다.
업무 범위: 합성 통계 조회, 승인 이력 조회, 파일 전송 상태 확인.
개인정보: 이 시연 사업에서는 실제 개인정보를 처리하지 않는다.
기간: 2026-11-11부터 2027-11-10까지.
구성: 웹 서버와 API 서버를 분리한다. 웹 서버에서 API 서버로 HTTPS 통신이 필요하다.
서버 사양: 웹 4 vCPU / 메모리 8 GB / 저장장치 100 GB. API 8 vCPU / 메모리 16 GB / 저장장치 200 GB.
망 구성: 웹은 DMZ, API는 내부망. 주소는 담당자 확인 필요.
운영: 매일 백업, 월간 복구 점검. 운영 권한은 승인된 담당자에게만 부여한다.
서버 주소, 실제 자산, 고객 정보는 포함하지 않은 시연 전용 자료이다.
