# SecurityAdvisor · 보안길잡이

공공기관 담당자와 정보보안·ICT인프라 전문가가 AI 인터뷰와 협의로 보안 서류를 준비하는 서비스입니다.

- 개발 시작점 구성: [Issue #1](https://github.com/team-khfc/Security-Advisor/issues/1)
- 선행 화면과 디자인 원본: [team-khfc/prototype](https://github.com/team-khfc/prototype)
- 현재 기준: 2026-11-06 프로젝트 지침, design v3.1

이 초기 커밋은 빈 저장소에 PR 기준 브랜치를 마련합니다. 실행 코드·최신 지침·검증 근거·팀 개발 안내는 `feat/1-team-development-starter` 브랜치에서 준비하며 PR 검토를 통해 통합합니다.

AI는 제안하고 사람이 확정합니다. 할당 완료와 협의 완료, 서류 확정과 방화벽 실제 적용을 구분합니다. 모든 시연 정보는 합성 자료만 사용합니다.
