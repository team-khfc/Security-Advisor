## 확인 범위와 제한

이 기록은 설치·업무 흐름의 재현성 검사이다. 외부 실제 모델의 답변 품질, 장비 적용, 대규모 부하·다른 운영체제 네이티브 설치를 검증했다는 의미가 아니다. 모의 AI는 고정 응답이며 실제 AI 분석으로 표시하거나 설명하지 않는다. 실제 모델 시연은 README의 live 설정과 관리자 연결 시험을 따로 수행한다.

GitHub의 `Judge installation` 워크플로는 Linux의 빈 DB 빌드·초기화·smoke·재시작 검사를 실행한다. 최신 결과는 저장소 Actions에서 확인한다.

## 실제 AI 추가 검증 · 2026-11-11

사용자 요청에 따라 로컬 기본 심사용 환경(`security-advisor-demo`, localhost:3000)을 기존 연동 도커와 같은 OpenRouter `deepseek/deepseek-v4.1-flash-1017`에 연결했다. 최대 토큰 4096, 대기 90초, temperature 0.2, 우선순위 5. 키는 Git에서 제외되는 로컬 `.env`에만 저장했고 원본 도커는 변경하지 않았다.

| 계정 / 시연 | 실제 호출 | 결과 |
|---|---|---|
| 안대웅 `an.dw` / 01 | 합성 기획서 문서 분석 | 확인 필요 상태로 분석 요약 저장, 실제 모델 참조 확인 |
| 안대웅 `an.dw` / 01 | 첨부 자료 기반 AI 인터뷰 | 응답과 F·B·A3·D1 근거 반환, 실제 모델 참조 확인 |
| 박소영 `park.sy` / 06 | 협의 결과 요약 | 최초 503(근거 검증 거부), 한 번 재시도 후 8항목 저장. 근거 키가 실제 기준본·현재 값에 존재하는지 확인 |
| 박소영 `park.sy` / 06 | 최종 초안 생성 | 실제 모델 본문 저장, AI_INFERRED·confirmed=false 확인 |

위 표는 실제 모델 호출의 추가 검증이다. 앞 절의 오프라인 검증 기록을 대체하거나 모든 모델 출력의 품질을 보장하지 않는다. 요약의 최초 실패 원인이 되는 개별 응답 항목은 서버가 공개하지 않으므로 추정하지 않았다. 자동으로 승인·확인·제출하지 않았으며 결과는 해당 시연 화면에서 확인할 수 있다.

재현 명령: README 6절의 `scripts/live-smoke.mjs --confirm-live`. 일반 smoke와 CI는 외부 유료 모델을 호출하지 않는다.
